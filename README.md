# System Design Studio

An interactive system-design practice workspace inspired by modern interview design tools.

## Core features

- File-based system design workspace with multiple diagrams/documents
- Infinite-style canvas with draggable nodes and directional connections
- Component palette for clients, services, databases, queues, caches, load balancers, storage and external systems
- Properties inspector for editing components and connections
- Markdown notes/specification panel
- Autosave to browser localStorage
- Import/export workspace as JSON
- Starter templates for common system-design problems
- Dark, interview-focused UI

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Stack

React + TypeScript + Vite + React Flow + Lucide React
